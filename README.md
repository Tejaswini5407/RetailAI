# RetailAI — Intelligent Demand Forecasting and Inventory Optimization Platform

## Overview
RetailAI is a multi-tenant retail demand forecasting and inventory intelligence platform. It leverages historical sales data and machine learning to forecast store-and-product level daily demand and convert predictions into actionable inventory recommendations.

## Tech Stack
- **Frontend:** React (Vite)
- **Backend:** Java 21 + Spring Boot 3.x (Maven)
- **ML Service:** Python 3.10+ + FastAPI (Uvicorn)
- **Database:** PostgreSQL (future)

## High-Level Architecture
```text
React
  ↓
Spring Boot
  ↓
PostgreSQL (future)

Spring Boot
  ↓
FastAPI ML Service (future)
```
